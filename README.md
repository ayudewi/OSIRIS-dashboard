# OSIRIS Dashboard

An interactive dashboard for exploring OSIRIS project data.

## Live Dashboard

[Open the OSIRIS Dashboard](https://osiris-dashboard.streamlit.app/)

## About

This dashboard was developed as part of the OSIRIS project and provides
interactive access to project information and work package data.

## OSIRIS

- [OSIRIS website](https://osiris4r.eu/)
- [OSF project](https://osf.io/8nyke/overview)

## Technology

The dashboard is built with:

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
- Google Drive

## Data

The dashboard retrieves its data from the project's shared data source.
Access credentials and secrets are not stored in this repository
